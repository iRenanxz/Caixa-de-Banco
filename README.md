# 🏦 Simulador de Caixa Eletrônico Bancário

Um sistema simples, eficiente e interativo que simula as operações fundamentais de um caixa eletrônico (ATM).
Desenvolvido para rodar diretamente no terminal, este projeto aplica conceitos de controle de fluxo, funções e
manipulação de estado em programação.

## 🚀 Funcionalidades

O sistema conta com as 4 operações principais exigidas para uma experiência bancária básica:

1.💵 Depositar: Permite a entrada de valores para somar ao saldo existente. Inclui validações para garantir
que apenas valores positivos sejam depositados.
2.💸 Sacar: Permite a retirada de valores do saldo, com validações automáticas para impedir saques de valores
negativos ou superiores ao saldo disponível.
3.💰 Consultar Saldo: Exibe o saldo atual disponível na conta do usuário de forma clara e formatada.
4.🚪 Sair: Finaliza a execução do programa com uma mensagem de despedida em segurança.
